FlowBot in NS Flow v3.7.0

FlowBot is optional and currently supported on Windows only. Install Codex
separately, then use Sign in with ChatGPT in FlowBot. The release contains no
Codex binary, account credentials, or pre-signed-in session. Account permissions
and usage limits apply. Normal NS Flow tools do not require AI chat.

The 28-topic app guide and all chat formatting files are bundled locally.
The optional confidential ROE policy corpus is excluded from this standard
release pending an approved restricted distribution path.
Relevant guide excerpts accompany explicit user messages. No live NetSuite
records, notes, activity, or files are automatically shared. FlowBot cannot
browse or perform NetSuite actions. Conversations remain in the open page only;
refreshing or closing the page clears them. ChatGPT recent history does not
provide an archive of these chats.

Apple Silicon: regular NS Flow workflows remain packaged, but this build does
not discover the Codex runtime or support FlowBot sign-in on macOS. Native Mac
execution has not been tested on this Windows workstation.

This is a local repack, not an online publication or a new stable declaration.
