NSCORP Companion App

Fresh installation

1. Extract this entire ZIP to a folder you can write to, such as Documents\NSCORP Companion App.
2. Keep the app, runtime, and both batch files together. Do not move files out of the extracted folder.
3. Double-click Start NSCORP Companion.bat.
4. The app opens in your default browser. Choose Chrome or Firefox, then use the matching Launch NSCORP button.
5. Sign in to NSCORP in the browser window opened by the app. Continue your NSCORP work in that window while using Companion.

Updating an existing installation

1. Close Companion with Stop NSCORP Companion.bat.
2. Extract the new full package into a new folder, or replace the old package files after Companion is closed.
3. Start it with Start NSCORP Companion.bat.

Notes

- Chrome and Firefox must already be installed on the computer.
- The package includes the Companion runtime and Firefox driver. No separate installation is required.
- The app works through your signed-in NSCORP browser session. It does not require an API key.
